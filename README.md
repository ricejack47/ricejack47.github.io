# Jack Rice Portfolio

Static portfolio site with four project pages and scroll-reveal motion.

## Hosting

Recommended: **Netlify** or **GitHub Pages**. Upload the contents of this folder (or push them to a GitHub repository) and set the publish directory to the folder containing `index.html`. Both options provide free HTTPS and a shareable URL. Netlify is easiest for drag-and-drop; GitHub Pages is best if you want version history.

Before publishing, replace `jack@example.com` in `index.html` and the project pages with your preferred email, and replace the systems-lab placeholder with the real third project details. The current live Wix draft can remain online while you test the new site; switch your portfolio link only after you are happy with the hosted preview.
