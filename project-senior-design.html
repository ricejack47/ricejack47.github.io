Wildfire Mesh
Detection System

A two-semester senior design project exploring resilient, distributed wildfire detection and data delivery.

Project timeline

This is a two-semester Senior Design project that began in Fall 2026. The team is currently in the first planning and design phase, with a completed system expected by May 2027.

System concept

The project is a wildfire detection system built around microcontrollers, smoke sensors, LoRa radios, LoRa network interface controllers, and 4G/5G communications. Nodes will monitor conditions in the field and deliver data to a base station, helping provide early awareness of possible wildfire activity.

Resilient mesh networking

A core goal is to preserve data delivery when normal infrastructure is disrupted. If the base station or cellular radios become unavailable during a power outage, failure, or physical damage, the microcontroller nodes are intended to form a mesh network with one another. That redundant path can help route information through remaining nodes rather than relying on a single point of failure.

Current status

We are still in the initial stages of planning, research, and architecture design. Check back as the project develops into prototypes, testing, and a completed field-ready system.
