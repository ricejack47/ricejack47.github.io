01 / JAVA · OBJECT-ORIENTED PROGRAMMING

Yahtzee
Java Game.

A game engine designed to make the rules reusable, extensible, and clear.

⚄⚂⚅

Objective

Create a game similar to Yahtzee in Java while using inheritance and polymorphism to share behavior across scoreboxes.

What I explored

Different scoring combinations share the same foundations: storing a score, exposing a display name, and checking whether a rolled combination satisfies the rule.

KEY IDEAS

  • Inheritance
  • Polymorphism
  • Abstract classes
  • Reusable APIs
